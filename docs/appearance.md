# 外观与字号实现

Windows 桌面应用使用 FluentAvalonia 控件主题。共享界面通过字体、字号和行高资源实现排版，Android 继续使用移动端主题。字号设置保存到本机 appearance.json，旧文件缺少该字段时采用 100%。

界面字号的三个档位为 100%、115% 和 130%。切换时，应用按基础字号计算覆盖资源，由动态资源绑定更新已打开的页面。每次计算都使用基础值，切换多次不会累计放大。标题和正文的行高随字号一起缩放。

喊话内容的显示字号由消息展示选项控制。它使用单独的设置，避免改变操作界面的字号时影响教室投影。

项目结构、协议、构建和部署流程见 [ClassShout 文档站](https://docs.wrd1145.top/)。
