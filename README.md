# ClassShout · 课堂喊话

用 Windows 或 Android 教师端向教室电脑发送文字、语音和图片。教室端可朗读文字、播放语音，并在屏幕上显示消息。

1. 从 [下载页](https://github.com/WRD1145/ClassShout/releases/latest) 获取教师端和教室端。
2. 在教室电脑上打开教室端，在教师端的「设备」页扫描或填写教室地址。
3. 连接后，在「文字」或「语音」页发送喊话。跨网络使用时，请按文档配置中继服务器。

可在外观设置里调整界面字号。教室大字区的喊话字号可在发送时单独设置。
